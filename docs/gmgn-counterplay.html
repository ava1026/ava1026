00 — 提取

v8 里属于产品侧的，是这七条

把 v8 的十五页过一遍，能落到产品排期上的是下面这些。右列是它改变了什么——不是复述，是对我们做法的影响。

v8 的产品侧内容性质对我们的产品做法意味着什么
三个功能卡在同一道墙上——止盈止损、真限价单、自动跟单，都要求平台能代用户签名，而 Privy 分片密钥必须由前端拉 share、本地重组 口径升级 从「我们多一个功能」升级为「这类功能它的架构给不了」。素材保质期变长，不怕它下周补上。见 §03 战役 ③
产品债集中在资金进出，不在速度——卖不出（gas $0.1 → $0.95 后最低卖出门槛约 $2）、入不进（Apple Pay / Cash App / 非美银行卡持续失败；德国用户看不到任何入金选项）、拿不走（仅 SOL / USDC 可提现，其他资产须导出私钥） 新事实 我原来的承接方案只盯「出金复杂」。真正结构性的是小仓位卖不出去——这是死锁，不是体验差。见 §03 战役 ④
它的速度机制被产品侧核实：USDC 先到 relay，再分发到各链；我们是单链对单链，所以更快08-13 核实，非推断 硬证据 「执行可靠性」这条主线终于有了机制层解释，不只是跑分。同时它直接决定 USDC relay 的边界——见 §01
它在主动补短板：已公开回应费率、给出 $0.10 floor 口径并预告 Solana 升级后继续降；同期上线 Clans 与 social perps；但 USDC 统一跨链＝速度天花板，改不动 判别标准 这条给了「窗口期 vs 结构性」一个来自对手行为的验证。费率 / 本地化 / 出金体验都别当护城河讲。
用链上数据审计跟单质量——关联地址识别 · 前置建仓检测 · 跟单者盈亏分布 同向印证 与我这边独立得出的战役 ①② 收敛到同一处。v8 的话说得更准：我们的社交层卖的是可信度，不是 feed 形态
托管信任危机：2026-08-02 ToS 允许第三方以未加密方式传输私钥、可无通知封号；2026-08-03 / 08-07 假客服骗局，已有实际盗资事件 新事实 「攻它的自托管叙事」从技术论证（Privy 持恢复分片）升级为它自己写进 ToS 的条款。但用法要克制，见 §06
它的官方响应模式「清缓存 / 切节点」，已被用户与我们的「检查 ms / fps / 切代理」并列批评 连带伤害 这是我们自己的债，不是它的短板。打「执行可靠」之前得先把客服口径改掉，否则素材反噬。见 §05

没有提取的部分：增长线（抄 B 不碰 A、UGC 定价、素材主轴）、渠道线（跨 BD 动员存量关系、盯合约到期窗口）、以及成本之争与观察哨——那些归 v8 主线，本文不重复排优先级。唯一交叉的是造星机制，因为它需要产品侧交付东西才能跑，见 §04。

01 — 今天要定的

USDC relay 的边界

这是我自己排的第 ④ 条，v8 把它标成了冲突项

我 08-11 排的四条里，第 ④ 条是「USDC 采用与 FOMO / PF 相同的 relay 跨链方案」。v8 把「USDC 统一跨链」列为对方的速度天花板与观察哨之一——意思是它一旦放弃，说明它要来抢专业交易员。

两件事同时成立就变成：我们正在把对手的结构性缺陷，排进自己的路线。

我当时的两难原话是「因为自动跨链，实际就把自己拉下去了；但是不能自研」。现在有了 08-13 产品侧核实的机制事实，这个两难可以拆开了：

路径后果
FOMOUSDC 先到 relay，再分发到各链多一跳，天花板锁死在 relay 的分发延迟上
我们单链对单链更快，且这是我们唯一说得清机制的速度优势

建议的边界（要在内部过稿前定下来）

USDC relay 只作为入金层与新用户便利层，不进入老用户的主交易路径。

  • 这与我自己在第 ④ 条里写的「交互与判断层区分新老用户策略」是一致的——不是推翻，是把「区分」写成一条不可逾越的线。
  • 产品上的具体落法：relay 路径与直连路径在交易确认页显式分叉，默认值按用户分层给，但老用户的默认永远是直连，relay 只能由用户主动选。
  • 验收口径：老用户主交易路径上 relay 占比 = 0。这条要能被监控查出来，不能只写在文档里。

不定这条边界，我们会主动交出唯一的结构性优势，而「打执行可靠性」这条主线同时失效——两个损失是一起发生的。

顺带解掉一个对称性问题。v8 的观察哨 ③ 是「FOMO 是否放弃 USDC 统一跨链」。如果我们自己也在用同一套方案而不设边界，这个观察哨会变成自打。边界一定，观察哨就重新成立——因为我们用它做入金，它用它做主交易路径，这是两回事。

02 — 判别标准

先扔掉一半的「优势」

能力对照表里我们领先 9 项。但领先不等于可以押注。区别只有一个：它是没做，还是做不到。

类型判据属于这一类怎么用
窗口期差距 它有钱、有速度，技术外包反而让它上得更快。v8 已给出行为证据：已公开回应费率、给出 $0.10 floor 口径并预告 Solana 升级后继续降；同期上线 Clans 与 social perps 费率 · 本地化 · 出金体验 · 新链覆盖 · 风控误杀 当窗口 抢时间差，不进产品叙事
结构性差距 改它要动供应商架构或账户体系，代价是重做产品。USDC 统一跨链＝速度天花板，改不动 内盘 · 自研链上数据 · 服务端签名能力 · 单链对单链的执行路径 当支点 可以围绕它做长期叙事

为什么必须先过这道筛子

Robinhood Chain 2026-07-01 主网上线，创始人 07-05 对「支持 RH 链」只回了一个 👀，我们 07-13 就在链上抓到了它的完整跨链交易——从表态到落地 ≤ 8 天。

推论：任何「FOMO 还没有 X」型的机会，默认寿命按一个季度估，不按一年。费率这条它 08 月已经动手了，就是现成的例子。

03 — 【打】

四个咬合点

战役 ① 可验真的战绩

这是唯一一条用我们的长板直接打它的长板的路。FOMO 最强的能力是社交，而社交的燃料是榜上那些亮眼 PnL。

问题不在「它造假」，在「它的口径不可验真」

机制事实：持仓记录区分 transferred / bought，排行榜 PnL 不区分。一个把已有盈利仓位转进来的人，和一个在站内从零买出这个收益的人，在榜上长得一模一样。

一手样本：claymore（@claymorepx）确认自己是 FOMO 30 日榜第 20 名、PnL +$278,533.79，而仓位性质为 transferred（转入），主要交易在 GMGN 与 Robinhood。v8 要求保留的客观补充：claymore 自述动机是移动端体验好、社交曝光强，不完全是被动配合平台策略——引用时这句不能省。

表述边界：单个当事人自述只能证明口径存在歧义，不能推广成「FOMO 榜普遍造假」。我们做的是提供一个可验真的版本，不是指控它。

产品动作

  1. 榜单每一行标本金来源。按链上把仓位拆成「站内买入 / 外部转入 / 关联钱包内转 / 空投」，PnL 默认只按站内买入部分计，转入部分单列注明。这不是加个字段，是换一种榜的定义。
  2. 跟单质量审计（v8 第 6 条，产品化）。三件事做成代币页与个人页上的常驻模块：关联地址识别 · 前置建仓检测 · 跟单者盈亏分布。最后一项是关键——它把「跟这个人的人赚没赚到钱」变成可查的数，而不是看他自己的 PnL。
  3. 跟单前体检。点进任何一个可跟的人，先看三个链上事实：本金来源、是否与该币项目方钱包有资金往来、历史卖出后代币的承接情况。
  4. 把体检覆盖到 FOMO 的账号。解析 relay 交易之后（见地基），我们会是唯一能对 FOMO 榜上账号做这套体检的终端。

它为什么跟不了：要区分 transferred / bought 并追资金关系，需要一整条自研链上数据管线。它路由、跨链、密钥、入金、出金全部外包——数据是它整个技术栈里最没有的那一块，它审计不了自己。

战役 ② 进场点位分布

FOMO 的跨链只询价 Uniswap V3 标准 AMM，未毕业代币无法交易。这是 Relay 报价源的边界，不是「暂时没接」。结果是它的用户结构性地只能在毕业之后进场。

而它口碑里最扎心的抱怨恰恰是「所有那些交易者都会利用你提供退出流动性」「故意在即将下跌时推送买入警报」——官方至今未回应。

这两件事是同一件事，用户还没把它们连起来

「我总是在接盘」不是运气，是产品能力决定的进场位次。我们的工作是把这个因果画出来，而不是说出来。

  1. 代币页加「进场点位分布」。一条价格轴叠三层：内盘成本区、毕业价、各终端用户的平均进场价。不写一个字结论。
  2. 「毕业前后无缝」做成一条动线，不是两个功能：同一个代币页，毕业前后不换界面、不换入口，用户不需要知道「内盘」这个词。这与我排的第 ③ 条（首页热门列表改造、解决小白接盘）是同一件事的两端——那条解决「找得到」，这条解决「进得早」。

诚实标注

「各终端平均进场价」需要 relay 解析先跑通，当前 BSC / Base 仍有盲区。补齐前只上「内盘成本区 + 毕业价」两层，第三层留空并注明「统计中」。不要用不完整的数据画一条会被打脸的线。

战役 ③ 三件事，同一道墙

这是 v8 给产品侧最有价值的一条。它把三个我们本来分开讲的功能差，收敛成一个架构差。

能力它能做到的上限我们同一个根因
跟单Follow → 他成交 → 你收到推送 → 你自己点进去下单；你不在线什么都不会发生自动执行 真自动要求平台代用户签名。而 Privy 分片密钥必须由前端拉 share、本地重组私钥完成 → 用户不在场就签不了。要做真自动只有两条路：托管私钥（自托管叙事破功）或会话密钥 / 预授权——都不是一个季度的事
真限价单非链上真单；创始人公开承认非托管跨 5 链做真限价单「extremely technical」，只能先做 SOL真单
止盈止损用户投诉集中项，未交付已上线

v8 要求保留的两处不确定——引用前必读

  • 源材料称它「后期增加了更接近自动 Copy 的功能」，用词是「更接近」，未说明已实现全自动。
  • 跟单的真实执行率外部看不到（细粒度复制成交量属 App 内部数据）。

所以对外只说「它的跟单需要用户手动确认」，不要说「它没有跟单」。这条要写进素材审核清单。

产品动作

  1. 把「替你执行」提到叙事第一句，而不是功能列表第八条。一句话：它只能通知你，我们能替你执行。这是可验证的技术事实，不是营销修辞。
  2. 做「跟单风控」，不只是「跟单」。单笔上限、滑点上限、跟卖同步、黑名单（与项目方钱包有资金往来的地址不跟）。最后一项需要战役 ① 的数据能力——两条战役在这里合流，这是我们能做出「安全的自动跟单」而它两头都缺的原因。
  3. 止盈止损做成可当场演示的截图素材。v8 的素材主轴三点里，前两点（执行可靠性、资产安全）靠感受与叙事，这一点靠截图就能证——产品侧要保证它在演示路径上一次不挂。

战役 ④ 接住它的资金进出债

v8 把它的产品债定位在资金进出，不在速度。这条修正了我原来的方向——我之前只盯「出金复杂」，那是体验问题；真正结构性的是钱锁在里面出不来。

它的债细节官方态度我们的对位
死锁 买进去卖不出来SOL gas $0.1 → $0.95，最低卖出门槛约 $2 → 小仓位结构性无法卖出建议导出私钥去 Phantom 操作无此门槛
高 入金全面失效Apple Pay / Cash App / 非美银行卡持续失败；德国用户看不到任何入金选项；借记卡最低约 $10、安卓难小额充、PC 端不能用卡官方与志愿者引导改走加密直充 / P2P / 好友代充不经手法币，无此链路
高 出金极度受限仅 SOL / USDC 可提现，其他资产须导出私钥外包给 Spritz，不在 App 内闭环链上出金，闭环内
高 托管信任危机2026-08-02 ToS 允许第三方以未加密方式传输私钥、可无通知封号；2026-08-03 / 08-07 假客服骗局，已有实际盗资事件—用户自持
中 风控误杀新 launchpad 池代币被判 honeypot → 买按钮禁用、无法 DCA称自动化风控不可自助覆盖，只能开工单等复核可覆盖
中 稳定性Privy 依赖导致崩溃 + 随机退出；ETH / BNB 自动 wrap 致用户无 Gas——

出口已经开了，而且是它自己开的

它在两处高优主题里官方建议用户「导出私钥到 Phantom 等外部钱包操作」——一次是为了卖掉小仓位，一次是为了提非 SOL / USDC 资产。它把用户往外推，我们只需要在门口接住。

产品动作：迁移引导路径

  1. 一键导入私钥 / 一键接管持仓 / 迁移落地页，把迁移摩擦降到最低。触发时机就对着它那两个场景：卖不掉的小仓位和提不走的非 SOL 资产。
  2. 「导入地址即补全 FOMO 历史」——用户填一个地址，我们把他在 FOMO 上被 relay 打散的买卖重新归属好、连成完整的持仓与盈亏曲线。他在 FOMO 自己都看不到这么清楚。
  3. 代币页 Trades 的 fomo 子 tab（GMGN-8665 已立项）——把「看不到」反手做成「看得比别人清楚」。

两条红线

  • 合规：目前我们把 relay 交易解析为「转入 / 转出」而非「买 / 卖」，是为了免责——因为无法识别投毒，攻防对抗后对方已把投毒金额提高到 50~100U。所以上面三条动作必须带标注与可信度提示兜底，不能直接当用户的真实战绩展示。产品侧要出这套标注规范，是前置交付物，不是可选项。
  • 叙事克制：「导入私钥」这个动作本身敏感。文案只讲用户要解决的问题（把卖不掉的仓位拿回来），不要去讲它的 ToS 或盗资事件——那是 KOL 号可以讲的，官方产品文案讲了就变成 hit piece，反噬我们自己的资产安全叙事。

地基：这不是止血，是三条战役的前置条件

主报告 §10.2 把 Relay 交易解析修复（GMGN-8687 / 8688 / 8689 / 8665）列为「P0 止血」。按本文的拆解，这个定性低估了它：战役 ①（对 FOMO 账号做体检）、②（各终端平均进场价）、④（导入地址补全历史）三条都站在它上面。地基的排期 = 三条战役的启动时间。

根因：FOMO 买单走 Relay 代发，relayer 先在 DEX 买下，再由路由合约 0xb92fe925dc43a0ecde6c8b1a2709c170ec4fff4f 转给用户钱包。用户钱包既不是发起方也不是接收合约，只出现在最后一跳转账里。修复方向是按「路由合约收币后转给谁」定归属。第三方（Debot / basedbot）已经能解析，说明这不是不可解的技术问题。

04 — 【抄】

造星机制里，产品侧要交付的那部分

v8 把造星机制归在增长线，但它跑不起来的原因在产品侧：没有素材生产工具，UGC 就没有原料。这一节只写产品要交付什么，不重复排增长的优先级。

要抄的是动力源，不是形态

机制只有两个零件：24h 刷新榜（榜单终身制会被大户永久霸占，24 小时刷新制造「人人都有机会」）＋ 官方转发（给社交货币，不给现金）。交易员原话：「The 24h anyone can jump to it — that's the secret sauce」。

不需要复制 feed，只需要复制「让普通人有机会被看见」这个动力源。现金成本≈零。

产品侧最小交付集

  1. Profile / 战绩页 / 可分享 PnL 卡——把素材生产工具化。没有这个，UGC 活动是空转：人拉进来了没东西可发。
  2. 24h 榜，且区分 bought / transferred。这一条同时是产品诚实和天然的对比叙事——与战役 ① 是同一个数据能力的两个出口，做一次，两处用。
  3. 榜要能展示「亏损但仍在场」，不只 PnL 排名。PF 的 feed 已经在生产这类内容（−$104 配 "im cooked" 仍有赞）。信仰稀缺性正在被别人先占——而这类内容只有真实数据撑得住，造出来的盘做不出「亏着还在」。

验收判据（省掉一轮「要不要加预算」的争论）

v8 给的三阶段曲线提供了一个可验收的判据：不必等交易量指标才知道成不成——判据是外部成名 KOL 是否开始主动找上来。在那之前都还在孵化期，该做的是持续点名 + 官方转发，把个案做成模板，不是加大付费。

只抄榜单与曝光这一层，不抄造盘

它飞轮的燃料是拉盘——渠道拿到的是账面数字与曝光，卖不掉（Dani 亲历 1万 → 7万，卖出即归零，无承接盘）；有真实承接盘的币则直接被大户 rug。踩这个坑不是钱的问题，是品牌与 KOL 合作关系的问题。

反过来看：Dani 这类高声誉交易员正因为这一点主动留在我们这边（「99% of all my trading is still GMGN」）——这是目前最实的一张牌，也是我们的榜必须真实的商业理由，不只是道德理由。

一条来自渠道线、但必须由产品接的推论

PF 挖角开的是 约 $20K 签约 + 约 $30K/月，要求永久删除 FOMO 账号并签排他——之所以要求删号，是因为站内影响力迁不走，账号本身就是资产（X 粉丝跨度 10.7× 进了 FOMO 塌缩成 2.8×）。

所以盯合约到期窗口只解决时机，不解决筹码。能挖动这批人的只有一件事：换到你这儿，我的观众还在不在。渠道线与社交层改版不能分开排期——窗口来了而我们没有承接观众的产品，人也接不住。这是上面那三条最小交付集要尽快落的真正原因。

05 — 【建】

先让宣传站得住

打「执行可靠」之前，我们自己有两笔债要清

  1. 推送延迟 6–20 min（对比 Dexscreener 近实时）。不修，「快」的宣传会自我反噬——素材主轴第一点直接无从落地。
  2. 客服口径。v8 记了一条连带伤害：它的官方响应模式「清缓存 / 切节点」已被用户与我们的「检查 ms / fps / 切代理」并列批评，认为两家都在逃避责任。我们在同一句吐槽里被点名。打可靠性之前必须先把这套应答模式改掉。

这两条不是「顺便修一下」——它们是所有对外叙事的前置条件。宣传比修复先落地，等于自己给对手递素材。

把优势从「感受」变成「可验证的数」

我们说执行快、成功率高，目前靠的是用户感受。而 08-12 社群监控刚好给了一个窗口：DeBot 24 小时内两轮机房故障 + K 线严重延迟、卖出成交价严重偏离（11k 市值仅卖到 2.7k）；Axiom 集中爆发无法买入、成交迟迟不填。社群里已出现有机口碑——用户主动说「Ave 与 GMGN 很少出现类似宕机」。

  1. 执行可靠性可视化：成功率 / 滑点 / 耗时对外可查。这是把第三方背书窗口转成长期资产的唯一方式——窗口不会持续，数会留下。
  2. 机制层解释一起给出：单链对单链 vs USDC 先到 relay，再分发到各链。有了这条，「快」就不只是跑分，而是结构决定的。
  3. 修 K 线全站卡死（08-04~05）、Stonk 类 token 池匹配缺失。同属「可靠性叙事的前置」。

口径护栏（沿用 v8 已成文的那条）

让 KOL 讲自己的真实体验，不做 hit piece——对账号更安全，转化也更好。官方号只做产品对比不点名；KOL 号可攻击，但不由我方供稿。

06 — 不做什么

四件明确不追的事

不追为什么改为
不抄社交产品形态（feed / Clans / Thesis） 抄形态抄不出网络效应，而且它的网络效应地基是不可验真的榜。抄形态等于把它的地基一起抄过来。 抄动力源（§04）、打地基（§03 战役 ①）。我们的社交层卖的是可信度，不是 feed 形态。
不主动挑起费率战 我们是 1% 固定比例；它是分段固定费（≤200U 每笔 0.95 USDC、200–10,000U 0.5%、≥10,000U 0.05%）。盈亏平衡点在 $95——之上我们全线更贵。而且它已经在降。 被问到再按分段如实回应。大额段是否跟进属于定价决策，需单独立项。
不把 ToS / 盗资事件写进官方产品文案 2026-08-02 的 ToS 条款和假客服盗资是硬事实，但由官方号讲就是 hit piece，会反噬我们自己的资产安全叙事。 只用可验证的技术事实（Privy 持恢复分片、分片密钥需设备在场）。ToS 那条留给 KOL 号，且不由我方供稿。
不追「跨链无感」的第二步 07-14 会议结论：自建跨链桥复杂度极高、不现实，Relay 是唯一可行方案。那是 BD 问题，不是产品问题。 产品侧只做第一步——统一 USDC 余额 + gas 代付，体验的 80% 在这里。且严守 §01 的边界：不进老用户主交易路径。

08 — 待核

会改结论的四条

① Apple Pay 是否已被移除　最高优先级

两个口径直接冲突。外部整理仍把 Apple Pay 入金列为它最强的护城河（约 68,000 首次买币用户 / 约 $25M），理由是这是它唯一「一次性建设、永久生效」的获客通道；而我方 08-13 的产品债清单说它疑似已被移除，入金全面失效、官方引导用户找朋友代充。

对产品侧的影响是直接的：主报告 §9 能力对照表现在写的是「Apple Pay 直接买 → FOMO 明显领先」。如果移除属实，那一行要改，而且它「零门槛进人」这一环出现结构性倒退——那是整条飞轮的入水口。今天就该核。

  • ② 我们的持仓来源解析在多链上的准确率是多少？战役 ① 和 24h 榜的「区分 bought / transferred」全都建立在这上面。这条没量化之前，不要对外承诺「可验真」。
  • ③ relay 解析修复后，BSC / Base 的归属准确率能到多少？决定战役 ②④ 的第三层数据能不能上。
  • ④ FOMO 的排行榜口径是否会变？它持仓页已经区分 transferred / bought，说明数据结构里有这个字段，只是榜没用。改榜口径的成本可能远低于我们的假设——它一改，战役 ① 的锋利度会下降（但跟单质量审计与资金关系追踪它仍然做不了，因为那需要自研数据）。建议加进 v8 的观察哨。

与 v8 观察哨的衔接

v8 的观察哨 ④「钱包架构是否从 Privy 分片改为托管或会话密钥」是观察哨 ②「是否上线限价单 / 止盈止损 / 真自动跟单」的前置信号——三个功能卡在同一道墙上，架构一动，② 会成批出现。产品侧的对应准备是：战役 ③ 的叙事一旦失效，重心要立刻移到战役 ①（数据可信度），因为那条不受它钱包架构影响。
